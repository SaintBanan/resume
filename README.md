Все коммерческие проекты, в которых я участвовал, являются проприетарными и не могут быть опубликованы полностью. В этом репозитории я выборочно выкладываю отдельные файлы и фрагменты кода, чтобы продемонстрировать свой стиль и подходы к решению задач.

## Структура репозитория

| Директория | Язык / Технологии | Краткое описание |
|------------|-------------------|------------------|
| `/android` | Java, Android SDK | Фрагменты Android-приложения: работа с сетью, БД, кастомные компоненты, макеты. |
| `/frontend` | JavaScript, jQuery, CSS | Примеры фронтенд-логики и кастомизации интерфейсов, стили. |
| `/php` | PHP 7.2+, Webasyst | Примеры плагинов, API-интеграций, работы с БД, метообновлений. |
| `/python` | Python, Qt | Фрагменты микросервисов, Telegram-ботов, обработки данных, ORM, графика. |
