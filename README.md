Все коммерческие проекты, в которых я участвовал, являются проприетарными и не могут быть опубликованы полностью. В этом репозитории я выборочно выкладываю отдельные файлы и фрагменты кода, чтобы продемонстрировать свой стиль и подходы к решению задач.

## Структура репозитория

| Директория | Язык / Технологии | Краткое описание |
|------------|-------------------|------------------|
| `/android` | Java, Android SDK, Jetpack | Фрагменты Android-приложения. |
| `/frontend` | JavaScript, jQuery, HTML, CSS | Примеры фронтенд-логики и кастомизации интерфейсов. |
| `/php` | PHP 7.2+, Webasyst | Примеры плагинов, API-интеграций, парсинга, работы с БД, метообновлений. |
| `/python` | Python, Qt | Фрагменты API-сервисов, Telegram-ботов, обработки данных, ORM, UI. |
