Здесь представлены фрагменты кода коммерческого проекта на базе Webasyst, демонстрирующие подходы к вёрстке, клиентской логике и интеграции с серверной частью.

## Что здесь можно увидеть

- **Вёрстка и анимации** — карусель с навигацией (Swiper), карточки с флип-эффектом, кастомизация скроллбаров, hover-переходы
- **jQuery-плагин** — самописный плагин для управления шаблонами задач (создание, редактирование, удаление через AJAX)
- **Работа с DOM** — динамическое добавление/обновление элементов, делегирование событий, замыкания
- **Интерактивные компоненты** — диалоговые окна (jQuery UI), выпадающие меню, фильтры
- **Асинхронное взаимодействие** — отправка данных на сервер ($.post) с обработкой ответов
- **HTML-шаблоны (Smarty)** — построение страниц с динамическими данными, подключение стилей и скриптов, передача серверных переменных в клиентский код (JS) через json_encode, условные конструкции, подключение подшаблонов

## Ключевые технологии

- HTML5, CSS3 (flexbox, позиционирование, псевдоэлементы)
- JavaScript (ES5), jQuery, UI
- Swiper (карусель)
- Smarty (PHP-шаблонизатор)
- Webasyst Framework
