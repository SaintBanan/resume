Здесь представлены фрагменты кода коммерческих проектов на базе Webasyst, демонстрирующие подходы к построению серверной логики, работе с базами данных, парсингу данных и интеграции с API.

## Что здесь можно увидеть

- **API-контроллеры** — обработка AJAX-запросов, валидация, сохранение и обновление данных (шаблонов задач), работа с загружаемыми файлами
- **Классы парсеров** — наследование и адаптеры для различных источников, постраничный парсинг, обновление товаров, цен, скидок и остатков на складах
- **Базы данных** — выполнение SQL-запросов, вставка, обновление, выборки с JOIN, агрегатные функции, работа с моделями
- **Скрипты обновления (updates)** — миграции схемы БД (ALTER TABLE), добавление полей, конвертация и перенос данных для метообновлений
- **Работа с файловой системой** — загрузка и удаление прикреплённых файлов, сохранение изображений, экспорт конфигураций в PHP-файлы
- **Обработка изображений** — массовая загрузка по URL, распаковка ZIP-архивов, конвертация в JPG, ресайз, обрезка до квадрата с белым фоном, сохранение с привязкой к товарам и артикулам
- **Фоновые задачи (cron)** — массовая обработка данных, управление памятью и правами доступа, логирование
- **Интеграция с экосистемой Webasyst** — использование waRequest, waApplication, waConfig, работа с пользователями и правами

## Ключевые технологии

- PHP (ООП, MVC)
- MySQL (запросы, миграции)
- Webasyst Framework (модели, контроллеры, конфигурация, изображения)
- JSON (обмен данными)
- Работа с файлами (загрузка, удаление, ZIP-архивы, права доступа)
