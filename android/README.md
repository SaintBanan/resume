# Фрагменты Android-приложения

Здесь представлены фрагменты кода из коммерческого Android-приложения, которое я разрабатывал для управления сделками и фотофиксации работ подрядчиков. Полный код проприетарен.

## Что здесь можно увидеть

- **Сетевой слой** — примеры работы с REST API (Retrofit, обработка ответов)
- **Локальная база данных** — работа с Room (сущности, DAO)
- **UI и навигация** — фрагменты, ViewModel, RecyclerView, кастомные компоненты
- **Многопоточность** — примеры с AsyncTask, Handler, Thread
- **Авторизация** — управление токенами (JWT), работа с AccountManager
- **Push-уведомления** — кастомная обработка FCM, маршрутизация, дедупликация

## Технологии

- Java
- Android SDK
- Retrofit, OkHttp
- Room, SQLite
- ViewModel, LiveData
- Firebase Cloud Messaging
- Picasso

## Контекст

Приложение использовалось 30+ подрядчиками, обработано более 500 сделок. Реализовано автообновление без Google Play, конкурентный приём заявок и чат с поддержкой.
