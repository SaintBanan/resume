# Фрагменты Android-приложения

Здесь представлены фрагменты кода корпоративного нативного Android-приложения, разработанного для управления сделками и фотофиксации работ. Приложение использовалось 100+ инженерами и подрядчиками, обработано более 4 000 сделок. Реализовано автообновление без Google Play, конкурентный приём заявок и чат с поддержкой.

## Что здесь можно увидеть

- **Сетевой слой** — примеры работы с REST API (Retrofit, обработка ответов)
- **Локальная база данных** — работа с Room (сущности, DAO)
- **UI и навигация** — фрагменты, ViewModel, RecyclerView, кастомные компоненты
- **Многопоточность** — примеры с Thread, Async, Handler
- **Авторизация** — управление токенами (JWT), работа с AccountManager
- **Push-уведомления** — кастомная обработка FCM, маршрутизация, дедупликация

## Ключевые технологии

- Java
- Android SDK
- Retrofit, OkHttp
- Room, SQLite
- ViewModel, LiveData
- Firebase Cloud Messaging
- Picasso
