# API и интеграции для мобильного приложения

Эти фрагменты кода являются частью бэкенда для корпоративного Android-приложения. Они обеспечивают:
- Авторизацию и управление сессиями
- Push-уведомления о новых заявках, статусах сделок, сообщениях от службы поддержки
- Автоматическое обновление приложения

## Ключевые функции

- **`createSession`** — регистрация устройства пользователя (токен, ОС, версия приложения)
- **`removeSession`** — удаление сессии при выходе из аккаунта
- **`check_updates`** — проверка актуальной версии приложения и размера нового APK
- **`send_event`** — отправка кастомных push-уведомлений пользователям (с поддержкой JSON-данных)
- **`get_user_tokens`** — получение всех push-токенов пользователя для массовой рассылки

## Стек

- Python 3.9+
- SQLAlchemy (ORM)
- PostgreSQL
- Firebase Cloud Messaging (FCM)
- Loguru (логирование)
