В этом каталоге представлены фрагменты учебного проекта по анализу изображений с графическим интерфейсом на PyQt5. Проект демонстрирует навыки построения GUI, обработки изображений и визуализации данных.

## Что здесь можно увидеть

- **Графический интерфейс (PyQt5)** — создание виджетов для отображения изображений, рисование поверх них, обработка событий мыши (выделение областей, рисование меток)
- **Обработка изображений (OpenCV)** — загрузка, отображение, преобразование цветовых пространств, коррекция гаммы, баланс белого, гистограмма и обратная проекция
- **Сегментация** — интерактивное выделение объектов с использованием алгоритма GrabCut, управление масками
- **Вычисление показателей** — расчёт средней зелёности (GCC) по выделенным областям, сохранение результатов в JSON
- **Визуализация** — построение графиков зависимости GCC от времени с помощью Matplotlib
- **Навигация по изображениям** — листание, добавление новых изображений, получение даты съёмки

## Ключевые технологии

- Python (ООП)
- PyQt5 (GUI, события, рисование)
- OpenCV (обработка изображений)
- NumPy (вычисления)
- Matplotlib (построение графиков)
