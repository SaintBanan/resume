# Telegram-бот для сбора заявок

Фрагменты бота для автоматизации приёма заявок от клиентов

## Состав

- `bot.py` — основная логика (обработка команд, состояния FSM, отправка уведомлений)
- `bot_redis.py` — менеджер Redis для управления сессиями и ID заявок
- `gtables.py` — интеграция с Google Sheets (сохранение заявок, добавление комментариев)
- `adds.py` — вспомогательные данные (адреса, клавиатуры)
- `credentials.json` — ключ доступа к Google Sheets API

## Как это работает

1. Пользователь отправляет `/start`
2. Бот показывает список услуг / прайс
3. Пользователь оставляет контактные данные (имя, телефон)
4. Бот сохраняет заявку в Google Sheets
5. Уведомление отправляется администратору в Telegram
6. Через команду `/add_comment` можно добавить комментарий к последней заявке

## Ключевые функции

- **Redis** — хранение ID заявок и контроль права на добавление комментария
- **Google Sheets API** — сохранение данных и комментариев
- **Уведомления** — администратор получает сообщение о новой заявке и комментарии

## Стек

- Python 3.9+
- aiogram (FSM, команды)
- Redis
- Google Sheets API (gspread)
- python-dotenv
- logging
